# AI Data Analyst Agent

An LLM-powered application for automated dataset exploration, analysis, visualization, and reporting

## Main objectives
* Reduce repetitive manual work in basic exploratory and business data analysis.
* Enable question answering over CSV and Excel data without requiring the user to write code.
* Use deterministic calculations for numeric answers and a local LLM for planning and explanation.
* Deliver a working, testable application packaged with Docker.
